# 数学题图解工坊 (mathviz)

一个**纯前端、离线可用**的数学题 + 解题过程 + 实时图形工作台。

- 🤖 **AI 出题**：调用大模型现场出题并给出分步解答，然后**自动从解答里提取重要式子/几何条件**，变成可拖动调节的 2D / 3D 图形
- 📚 **题库生成**：21 个题型（解三角形、函数图像、圆锥曲线、解析几何、立体几何、平面向量）
- ✍️ **自定义题目**：把自己的题目粘进去，自动识别条件、画图、给解法
- 🎛 **一切都可调**：每个图形卡片下面有自己的参数滑块（边长、半径、系数、**二面角/夹角**…），拖动时题目数值、图形、读数、解题过程、答案**同时更新**
- 👀 **解题过程可选显示**：勾选框 / 按钮 / 逐步展开 / 全部收起；答案也能单独开关

## 一、怎么打开

### 方式 A：本地 HTTP 服务（推荐，地址栏是 http://）

**双击 `启动本地服务器.cmd`** —— 会自动选一个空闲端口（默认 8123，被占用就往后找）、打印网址、并自动用默认浏览器打开：

```
http://127.0.0.1:8123/
```

- 只需要 Windows 自带的 PowerShell，**不需要 Node、Python，也不需要管理员权限**
- 只监听 `127.0.0.1`，外网/局域网都访问不到，安全
- 想换端口：`powershell -ExecutionPolicy Bypass -File server.ps1 -Port 9000`
- 关闭那个黑窗口 = 停止服务

### 方式 B：直接双击 `index.html`

不用服务器也能跑（纯前端、经典 `<script>`、不读本地文件），只是地址栏是 `file:///...`。

> 两种方式功能完全一样。如果你要分享给同一台电脑上的其他浏览器/工具，用方式 A 更方便。

推荐浏览器：Edge / Chrome 等现代浏览器。

## 二、AI 出题（核心流程）

```
你的要求 ──► AI 出题 + 分步解答（Markdown + LaTeX）
                    │
                    ▼
        自动提取"重要式子/几何条件"
        （LaTeX → 可解析表达式 → 规范题目句）
                    │
                    ▼
      每个式子变成一张图形卡片（自带滑块，可实时调节）
```

两种用法，效果完全一样：

### 1）直接调接口（自带密钥）

左侧「AI 接口设置」里选服务商（DeepSeek / OpenAI / Kimi / 通义 / 智谱 / 硅基流动 / 本地 Ollama / 自定义 OpenAI 兼容地址），填 API Key 和模型名 → 选知识点、难度 → 点 **⚡ 用 AI 生成题目并作图**。

- 密钥只存在你自己浏览器的 localStorage，直接发给你选的 AI 服务商，**本站不经过任何中间服务器**。
- 本地 Ollama 不需要密钥。
- 若被浏览器跨域（CORS）拦截，会提示你改用第 2 种方式。

### 2）免密钥：复制提示词 → 粘贴回答

点 **📋 复制提示词**，把它贴到任意 AI 对话框（网页版 ChatGPT / DeepSeek / Kimi 都行），再把 AI 的**完整回答**用 **📥 粘贴 AI 回答 → 解析并自动作图** 贴回来。

想先看看效果，点 **🎬 看示例**（内置 7 段真实风格的 AI 回答：解三角形、导数与极值、正方体、直线与圆、圆锥、正弦型函数、椭圆）。

### 提取规则（能提出什么图）

| 解答里的式子 / 条件 | 生成的图形 |
| --- | --- |
| `y=x^3-3x^2+2`、`f'(x)=3x^2-6x`、`y=2\sin(2x+\frac{\pi}{3})` | 函数图像（自动选横轴范围，标注零点与极值） |
| `r=3\cos(3\theta)` | 极坐标曲线（玫瑰线等） |
| `\frac{x^2}{25}+\frac{y^2}{9}=1`、`x^2/16-y^2/9=1`、`y^2=8x` | 椭圆 / 双曲线 / 抛物线（含焦点、准线、渐近线、离心率） |
| `x^2+y^2=25` 与 `y=2x+1` | 直线与圆（圆心距、弦长、交点） |
| `AB=5,\ AC=7,\ \angle A=60^\circ` 或余弦定理代入式 `a^2=5^2+7^2-2\cdot5\cdot7\cos60^\circ` | 三角形（海伦/余弦定理那套结论） |
| 「正方体棱长为 2」「圆锥底面半径 3，高 4」「正四棱锥二面角 60°」… | 对应立体图形（3D，可旋转） |
| `D={(x,y)\|\|x\|+\|y\|≤1}` 加 `I₁=∬_D (2x²+tan(xy²))dxdy` 这类式子 | **平面区域上的二重积分**：画出积分区域（尺寸可拖）、逐项做奇偶性检验、数值算出每个积分、给出大小关系并**自动匹配选项** |

每个式子里的数字与字母都会自动变成**滑块初值**，所以出来的图天然是「可动」的。提取不到可作图的式子（纯代数、数列、概率题）时，会明确告诉你这一点。

AI 也被要求额外输出一段 ```figures JSON（列出值得作图的式子），有的话优先采用；没有也能靠上面的规则自动提取。

## 三、题库生成（21 个题型）

| 分类 | 题型 |
| --- | --- |
| 解三角形 | 已知两边及夹角、已知三边、已知两角及一边 |
| 函数图像 | 正弦型函数、二次函数、指数与对数、极坐标曲线 |
| 圆锥曲线 | 椭圆、双曲线、抛物线 |
| 解析几何 | 直线与圆的位置关系、两圆的位置关系 |
| 立体几何 | 正方体、长方体、正四棱锥（**二面角滑块**）、正三棱柱、圆柱、圆锥、球与内接正方体、正四面体 |
| 平面向量 | 数量积、`|a+b|`、`|a−b|`、夹角 |

点 **🎲 换一题** 换数值。

## 四、自定义题目

把题目粘进去就行，例如：

- `在△ABC中，AB=5，AC=7，∠A=60°，求BC的长和面积`
- `△ABC的三边为 a=3，b=4，c=5，求最大角`
- `y = 2sin(x) + 1`、`y = x^2 - 2x - 3`
- `椭圆 x^2/25+y^2/9=1`、`双曲线 x^2/16-y^2/9=1`、`抛物线 y^2=8x`
- `r = 3cos(3theta)`
- `圆 x^2+y^2=25 与直线 y=2x+1`
- `正方体棱长为3`、`正四棱锥底面边长4，侧面与底面所成角60°`、`圆锥底面半径3，高4`、`球半径2`
- 二重积分（可以直接粘 LaTeX）：`D={(x,y)||x|+|y|≤1}，I_1=∬_D (2x^2+tan(xy^2))dxdy，I_2=… ，(A) I_3>I_2>I_1 …`

识别到的数值会变成滑块初值；函数式里的数字与字母也自动变成参数。

### 两条通路：本地识别 / 交给 AI 解

| 按钮 | 做什么 | 适合 |
| --- | --- | --- |
| **📐 本地识别作图（离线、免费）** | 用内置规则识别条件 → 画图 + 给结论，**不联网、不花钱、瞬时出结果** | 三角形、函数、圆锥曲线、圆与直线、立体图形、二重积分这些标准题 |
| **🤖 让 AI 解这道题** | 把**你的题目原文**发给 AI（要求"不许改题"）→ 返回规范题目 + 分步过程 + 答案 + 关键式子 → 自动提取成可调图形 | 证明题、数列、概率、复杂综合题，或任何本地认不出来的题 |

- **没配 API 密钥也能用**：点「📋 复制解题提示词」（提示词里已经包含你输入的题目）→ 贴到任意 AI 网页版 → 把回答用「📥 粘贴 AI 解答」贴回来，效果一样。
- 本地识别失败时，提示里会直接建议你改用 AI 那条路。
- 地址栏也可以直接分享一道"AI 解好的题"：`?solve=<AI 的回答>&orig=<你的题目>`（都可 URL 编码）。

## 五、界面与操作

- **解题过程 / 答案**：`显示解题过程` 勾选框、`▸ 显示解题过程` 按钮、`逐步展开 / 全部展开 / 全部收起`
- **每个图形卡片**：标题（来自解答的第几步）、关键式子、参数滑块、实时读数、`重置视角 / 自动旋转 / 导出 PNG`
- **画布**：拖动 = 平移（2D）/ 旋转（3D），滚轮 = 缩放，双击 = 重置视角
- **分享 / 自动化参数**（写在地址栏里）：
  - `index.html?gen=solid_pyramid&seed=5&steps=1&answer=1`
  - `index.html?q=正方体棱长为3`
  - `index.html?aiDemo=derivative&steps=1`
  - `index.html?ai=<URL 编码后的 AI 回答>`
  - `&dbg=1` 会在图形下方显示画布尺寸与缩放系数（排查渲染问题用）

### 数据结构（想扩展时看这里）

生成器统一返回：

```js
{
  statement: '题干，公式写成 $...$',
  steps: [{ title: '第 1 步：…', body: '说明 + $公式$ 或 $$公式$$' }],
  answer: '答案',
  scene: { kind: '2d' | '3d', points: {...}, items: [...] },
  readouts: [{ label: '体积 V', value: '12.34' }]
}
```

- 2D 图元：`segment / polygon / circle / arc / line / ray / func / polar / curve / angle / ticks / point / text`
- 3D 图元：`face / edge / circle3 / sphere / angle / point / text3`；`edge` 的 `style:'auto'` 会按凸体消隐自动决定实线还是虚线
- 2D 场景里 `equalAspect: false` 表示横纵轴各自铺满（函数图像用），几何图形默认等比例

新增一个题型：写好 `make(rng)`（参数定义）与 `build(vals)`（题目 + 步骤 + 场景），注册到 `MV.Generators` 即可。

## 八、已知边界

- 3D 消隐基于「凸体」判定：正方体、棱柱、棱锥、圆柱、圆锥、球、正四面体都精确；凹凸体（带孔、挖槽）不会正确消隐。
- 自定义解析与 AI 式子提取都是**规则式识别**，覆盖上表列出的写法；识别不到会给出示例格式，不会乱画。
- 函数题的零点/极值/单调区间来自数值取样（1200 点）分析，界面与文案都标明「数值近似」。
- AI 提取的图形卡片数量上限默认 6 张（题干 1 张 + 每一步最多 1 张，按出现顺序，重复条件会自动去重）。
- 「AI 出题」需要你自己提供 API 密钥或走「复制提示词 / 粘贴回答」；网站本身完全离线。
- 二重积分目前支持**区域 + 比较大小**这类题（菱形 / 圆盘 / 椭圆域 / 长方形区域），被积函数用数值积分算出结果；区域形状（|x|+|y|≤a 这类）由滑块调节。一般区域的边界自动提取（`y≤f(x)` 之类）暂未支持。

## 九、部署到 GitHub Pages（可选）

本站是**纯静态、零构建**：所有路径都是相对路径，没有任何外部依赖，所以放到 `https://用户名.github.io/仓库名/` 这种子路径下也能直接跑（已实测）。

1. 登录 [github.com](https://github.com/) → 右上角 **+** → **New repository**
   - **Repository name** 填仓库名（只能是英文/数字/-/_，会出现在网址里），选 **Public**
   - **不要**勾 "Add a README file" → **Create repository**
2. 空仓库页面点 **uploading an existing file**
3. 打开本地的 `mathviz-github-pages` 文件夹，**双击进入**，在里面 **Ctrl+A 全选**（14 个项目），一起拖进浏览器的上传区
   - ⚠️ 拖的是**文件夹里的内容**，不是文件夹本身（否则会多一层目录，Pages 打开就是 404）
   - 判断：传完后仓库首页应**直接**看到 `index.html`
4. 底部 **Commit changes** → 再点一次 **Commit changes**
5. 仓库 **Settings** → 左侧 **Pages** → Source 选 `Deploy from a branch` → Branch 选 **main**、目录 **/ (root)** → **Save**
6. 等 1～2 分钟，刷新该页面，出现 **Your site is live at `https://用户名.github.io/仓库名/`**

以后更新内容：**Add file → Upload files** 把改动过的文件重新拖上去（拖整个 `js` 文件夹会保留子目录结构），Commit 后自动重新发布。

线上版本可以用仓库里的 `验证线上地址.mjs` 复查（改一下里面的网址）：

```bash
node 验证线上地址.mjs
```

它会检查首页、页面引用的全部静态资源、以及关键脚本的 HTTP 状态与 Content-Type，并对比线上/本地 `index.html` 的哈希（确认 GitHub 原样发布了文件）。
